# 同步控制器硬件

STM32G474 主控，2 路隔离 CAN、2 路隔离舵机 UART、USB-C、急停回路和继电器输出。116 × 90 mm，4 层板。

**这块板子还没有打样，也没有上电。** 下面的检查都是设计规则层面的，不能代替实物验证。

## 文件

| 路径 | 内容 |
| --- | --- |
| `docs/selection.md` | 选型依据，每项都写了来源 |
| `docs/bom.csv` | 物料清单。LCSC 编号留空表示还没确认，下单前要逐项核对 |
| `docs/schematic.pdf`、`docs/board_top.png` | 原理图和渲染图 |
| `gen/design.py` | **唯一的设计数据**，原理图和 PCB 都从这里生成 |
| `kicad/` | 生成的 KiCad 工程，可以直接用 KiCad 打开 |
| `fab/` | Gerber、钻孔和贴片坐标 |

## 重新生成

```bash
uv run python hardware/sync-controller/gen/make_all.py
```

顺序是原理图 → BOM → ERC → 网表比对 → 布局布线 → DRC 和原理图一致性 → 隔离带测量 → 制造文件，任何一步失败就停。布线要几分钟，`--skip-route` 可以保留现有布局。

修改设计请改 `gen/design.py` 或 `gen/gen_pcb.py`。直接在 KiCad 里改的内容，下次生成时会被覆盖；如果决定以后手工维护 PCB，就不要再运行布线这一步。

## 关键设计

- **每路接口独立隔离。** CAN 用 ISO1044BD，UART 用 ADuM1201BRZ，电源用 B0509S-1WR3 加 HT7550-1 稳压。没有用 5 V 输入 5 V 输出的模块，因为它轻载时电压可能超过 ISO1044 VCC2 的 5.5 V 上限。
- **控制板不从机械臂取电。** Star 的 3 针舵机座中间的电源针没有连接。隔离侧由板上的 DC/DC 供电。
- **急停是硬件回路。** 常闭急停触点和继电器线圈串联，按下后不经过任何软件就会释放。MCU 复位时栅极的下拉同样会让继电器释放。两路检测信号让固件也能知道发生了什么。
- **继电器只给信号用。** G5V-2 不能切断 48 V 电机电流，请用它去控制外部的接触器或驱动器使能。

## 布线

这块板子的布线由 `gen/gen_pcb.py` 里自己写的栅格 A* 布线器完成，带拆线重布和隔离域约束。它能保证 DRC 通过，但不会像有经验的工程师那样考虑回流路径、串扰和散热。**打样前请人工审一遍版图**，重点看 USB 差分对、CAN 差分对、DC/DC 周围和跨隔离带的区域。

## 打样前还要确认

- BOM 里 LCSC 编号为空的物料，以及所有封装和实物的对应关系
- Star 线束的针脚顺序和逻辑电平（目前来自公开资料，未用实物验证）
- 隔离带 1.00 mm 是**功能隔离**，不是安全隔离，不能当作安规爬电距离
- 嘉立创等厂家的 4 层板叠层和阻抗参数。USB 差分对没有做阻抗计算
- 板上没有放光学定位点（fiducial）。要贴片的话，确认厂家能接受或自行添加
- 急停端子不接急停按钮时，板子会一直处于急停状态，继电器不吸合。这是故意的，接线方法见 `docs/bringup.md` 第 2 步
